Checkpoint 1: predict before you run

x = 7
y = 2
x = x + y
print(x, y)

What does this print?

x = x + y calculates 7 + 2 and stores 9 back in x. y never changes.

4. Making decisions

Python runs the first branch whose condition is True and skips the rest. Indentation shows which lines belong to each branch.

Checkpoint 2: predict before you run

score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")

What does this print?

85 fails >= 90 and passes >= 80. Python stops at the first true branch, so it never checks >= 70.

5. Loops

A for loop repeats a set number of times. A while loop repeats while a condition stays true. The accumulator pattern starts a total at 0 and adds to it each pass.

Checkpoint 3: predict before you run

count = 0
for n in range(1, 10, 3):
    count = count + 1
    print(n)
print("count =", count)

What does this print?

range(1, 10, 3) starts at 1, steps by 3, and stops before 10: 1, 4, 7.
