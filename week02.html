1. Defining functions

A function is a named block of code you can run again and again. You define it once with def, then call it by name. Values you pass in are parameters; the value it hands back is its return value.

Functions can call other functions. This is how real programs stay readable: each function does one job.

Checkpoint 1: predict before you run

def double(n):
    n = n * 2
    return n

x = 5
y = double(x)
print(x, y)

What does this print?

Inside the function, n is a separate local variable. Changing it does not change x, so x stays 5 and y gets the returned 10.

2. Return versus print

print shows a value on the screen. return hands the value back so other code can use it. A function with no return hands back None.

Checkpoint 2: predict before you run

def greet(name):
    print("Hi", name)

result = greet("Ana")
print(result)

What does this print?

greet prints "Hi Ana" but has no return, so result is None. This is the most common bug in the practice task below.

3. Working with strings

A string is a sequence of characters. Each character has a position (index) starting at 0. Negative indexes count from the end. A slice s[start:stop] takes characters from start up to, but not including, stop.

Checkpoint 3: predict before you run

title = "Python Basics"
print(title[:3], title[-3:])

What does this print?

[:3] takes positions 0, 1 and 2 ("Pyt"). [-3:] starts three from the end and runs to the end ("ics").

4. Formatting with f-strings

Put an f before the quotes and place any expression inside { }. Add a format code after a colon: :.2f shows two decimals, :>8 right-aligns in 8 spaces.

Try it: change :.2f to :.0f, then remove the f before the quotes. What happens each time?
