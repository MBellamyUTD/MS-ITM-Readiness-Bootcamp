1. Lists and tuples

A list holds an ordered set of values in square brackets. Lists can change: you can add, remove and sort items. A tuple uses parentheses and cannot change after it is created, which makes it good for fixed records.

Checkpoint 1: predict before you run

nums = [3, 1, 2]
nums.append(5)
print(len(nums), nums[-1])

What does this print?

append adds 5 to the end, so the list has 4 items and the last one (index -1) is 5.

2. Dictionaries and sets

A dictionary stores key: value pairs, so you look things up by name instead of position. A set holds unique values with no duplicates.

Checkpoint 2: predict before you run

stock = {"pens": 4, "pads": 0}
stock["pens"] += 2
print(stock.get("ink", "none"), stock["pens"])

What does this print?

+= 2 raises pens to 6. get returns the default "none" for a missing key instead of crashing. stock["ink"] would have raised a KeyError.

4. Handling errors with try and except

When something goes wrong, Python raises an exception and stops. A try block lets you catch it and respond instead of crashing. Catch specific errors, like ValueError or FileNotFoundError, so real bugs are not hidden.

Checkpoint 3: predict before you run

try:
    n = int("ten")
    print("A")
except ValueError:
    print("B")
print("C")

What does this print?

int("ten") fails immediately, so print("A") never runs. Python jumps to the except block and prints B, then continues after the block and prints C.

5. Reading and writing CSV files

Use with open(...) so Python closes the file for you. The csv module splits each line into values. Everything read from a file is text, so convert numbers with int() or float().
