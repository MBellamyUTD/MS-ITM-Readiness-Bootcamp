1. Classes and objects

A class is a blueprint. An object is one thing built from that blueprint. The bookstore has one Book class but hundreds of book objects, each with its own title, price and stock.

__init__ runs automatically when you create an object. It stores the object's data in attributes on self, which means "this particular object."

Checkpoint 1: which statement is true?

One class, many objects. Each object keeps its own attribute values, and Python calls __init__ for you when you write Book(...).

2. Methods

A method is a function that belongs to a class. Its first parameter is always self, so it can read and change that object's attributes.

Checkpoint 2: predict before you run

class Counter:
    def __init__(self):
        self.n = 0
    def add(self):
        self.n += 1

a = Counter()
b = Counter()
a.add()
a.add()
b.add()
print(a.n, b.n)

a and b each have their own n. a.add() runs twice and b.add() once.

3. A readable printout with __str__

Printing an object shows something unhelpful like <Book object at 0x...>. Define __str__ to return the text you want instead.

4. Inheritance

A subclass inherits everything from its parent class and can add or change behavior. super().__init__(...) runs the parent's setup so you don't repeat it. Defining a method with the same name overrides the parent's version.

Checkpoint 3: predict before you run

class A:
    def hi(self):
        return "A"

class B(A):
    def hi(self):
        return "B"

class C(A):
    pass

print(B().hi(), C().hi())

B overrides hi, so it returns "B". C defines nothing, so it inherits hi from A and returns "A".

Practice task: the Book class

Build the class the bookstore will use everywhere. Book(title, price, stock) needs:

  • attributes title, price and stock
  • restock(amount) adds to stock
  • sell(quantity): if there is enough stock, subtract it and return True; otherwise change nothing and return False
  • value() returns price times stock
  • __str__ returns text like Python Basics ($12.50, 12 in stock)
